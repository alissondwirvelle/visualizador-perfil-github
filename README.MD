# Visualizador de Perfil do GitHub

Este projeto é um visualizador de perfil do GitHub simples, que permite buscar e exibir informações de usuários do GitHub.

## Funcionalidades

- Busca de perfil de usuário do GitHub.
- Exibição de informações do perfil, como nome, avatar, seguidores, seguindo, repositórios públicos.
- Links diretos para o perfil do GitHub e repositórios.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub API

## Como Rodar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/visualizador-perfil-github.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd visualizador-perfil-github
   ```
3. Abra o arquivo `index.html` no seu navegador.
